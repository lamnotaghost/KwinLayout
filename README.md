# Шаблоны окон для KDE Plasma 6

Эффект KWin, который сохраняет расположение нескольких окон и восстанавливает
его в пару нажатий — через переключатель в стиле Alt+Tab. Окна раскладываются
по плиткам KWin (Meta+T), поэтому границу между ними можно тянуть, и соседние
окна меняют размер вместе.

## Возможности

- **Кнопка на границе окон.** Поставьте два и более окна вплотную и наведите
  курсор на границу между ними — появится круглая кнопка:
  - клик — меню: сохранить расположение как шаблон, поменять окна местами,
    открыть настройки;
  - зажать и тянуть — меняется размер окон по обе стороны границы; граница
    останавливается, когда одно из окон доходит до своего минимального
    размера, поэтому окна не съезжают и не налезают друг на друга.
- **Переключатель шаблонов** по `Meta+Ctrl+L`: стрелки, Tab или повторное
  нажатие хоткея — выбор, Enter или клик — применить, цифры 1–9 — сразу,
  Esc или клик мимо — закрыть. Шаблон применяется к монитору под курсором.
- **Аккуратное применение шаблона:**
  - уже открытые окна плавно растягиваются и сужаются до своих мест;
  - если расположение уже совпадает с шаблоном — ничего не происходит;
  - если раскладка та же, а пропорции другие — сдвигаются границы плиток;
  - окно, которое уже стоит на своём месте, не трогается;
  - недостающие приложения запускаются и встают в свои плитки.
  - если у приложения открыто больше окон, чем мест для него в шаблоне,
    сначала появляется выбор окна с миниатюрами (клик, стрелки и Enter
    или цифры; Esc — назад);
  - расставленные и запущенные окна поднимаются поверх остальных.
- **Перетаскивание к краю экрана без Shift.** Если на мониторе используется
  раскладка Meta+T, окно, брошенное у левого или правого края, встаёт в плитку
  раскладки под курсором с её текущими пропорциями, а в углу (четверть высоты
  экрана сверху или снизу) — в верхнюю или нижнюю половину колонки. Пока окно
  у края, подсвечивается место, куда оно встанет. На мониторах без раскладки
  работает обычный быстрый тайлинг KWin.
- **Окно настроек** («Шаблоны окон» в меню приложений): создать шаблон из
  выбранных приложений и схемы разделения экрана, переименовать, удалить,
  упорядочить шаблоны, сменить горячую клавишу, выключить эффект.
  Редактор не даёт сделать часть меньше минимального размера окна
  приложения: ползунок пропорции останавливается на допустимом значении,
  слишком маленькая часть подсвечивается красным, и такой шаблон нельзя
  сохранить. Минимальные размеры эффект запоминает по открытым окнам, так
  что для приложения, которое ни разу не запускалось, проверки нет.

## Требования

- KDE Plasma 6 на Wayland (проверено на Plasma 6.6);
- для окна настроек: Python 3, PyQt6 и dbus-python
  (в Ubuntu: `sudo apt install python3-pyqt6 python3-dbus`);
- `kpackagetool6`, `kwriteconfig6`, `qdbus6`, `kstart` — входят в Plasma 6.

## Установка

```bash
./install.sh
```

Скрипт ставит эффект KWin, окно настроек и юнит systemd для запуска
приложений, включает эффект и перезагружает его. Повторный запуск обновляет
эффект без перелогина. Эффект также появится в «Параметры системы → Эффекты
рабочего стола».

Удаление (сохранённые шаблоны остаются в `~/.config/windowlayoutsrc`):

```bash
./uninstall.sh
```

## Устройство

| Путь | Что это |
|---|---|
| `kwin-effect/contents/ui/main.qml` | корень эффекта (`SceneEffect`); остальное грузит с меткой в URL, чтобы обновление подхватывалось без перелогина |
| `kwin-effect/contents/ui/Core.qml` | логика: поиск границ между окнами, шаблоны, раскладка плиток, перетаскивание к краю, хоткей |
| `kwin-effect/contents/ui/Handle.qml` | кнопка на границе окон |
| `kwin-effect/contents/ui/Overlay.qml` | состояние меню и переключателя, анимации перемещения окон |
| `kwin-effect/contents/ui/OverlayView.qml` | то, что эффект рисует на каждом мониторе |
| `kwin-effect/contents/ui/DropPreview.qml` | подсветка места, куда встанет перетаскиваемое окно |
| `settings/windowlayouts_settings.py` | окно настроек (PyQt6) |
| `systemd/windowlayouts-launch@.service` | запуск приложений из шаблона: код внутри KWin не может запускать процессы сам и вызывает этот юнит через D-Bus |

Шаблоны хранятся в `~/.config/windowlayoutsrc` — INI-файл с ключом
`Layouts/templates`, значение — JSON. Координаты окон записаны долями рабочей
области экрана, поэтому шаблон подходит для монитора с любым разрешением.

### Почему это эффект, а не KWin-скрипт

- В KWin 6 обычные окна скриптов не получают клавиатуру. Меню и переключатель
  сделаны полноэкранным эффектом (`SceneEffect`), как «Обзор».
- `SceneEffect` рисуется, только если KWin загрузил его как эффект: внутри
  KWin-скрипта он перехватывает ввод, но не отображается.
- Эффект заменяет картинку экрана целиком, поэтому под меню он сам рисует
  рабочий стол живыми миниатюрами окон (с учётом эффекта «Затемнение
  неактивных окон», если он включён).

```bash
journalctl --user -f | grep windowlayouts
```
